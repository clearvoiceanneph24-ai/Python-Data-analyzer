# Python Data Analyzer

### Python-Based Data Analysis and Visualization Project

## Project Overview

Python Data Analyzer is a Python project designed to process, analyze, validate, and visualize datasets using Python.

It demonstrates practical data analysis techniques, statistical calculations, CSV processing, and data visualization.

## Key Features

- Basic Statistical Analysis
- Advanced Statistical Analysis
- CSV File Creation and Import
- Dataset Validation
- Sales Performance Analysis
- Total Revenue Calculation
- Best-Selling Product Identification
- Bar Chart Visualization
- Pie Chart Visualization
- Automated Testing
- Error Handling

## Technologies Used

- Python
- Pandas
- Matplotlib
- Statistics
- Google Colab
- Jupyter Notebook

## Sample Dataset

The project uses sample sales data containing five products:

- Laptop
- Mouse
- Keyboard
- Monitor
- Headset

The project generates:

The project includes automated tests for:

- Dataset validation
- Revenue calculation

- Missing data detection
- Negative value detection

All implemented tests passed successfully.

## How to Run

1. Open the Jupyter Notebook in Google Colab.
2. Run the notebook cells in order.
3. Generate the sample CSV dataset.
4. Execute the analysis and visualization cells.
5. Review the generated reports and charts.

## Project Purpose

This project demonstrates practical Python programming, data processing, statistical analysis, and visualization skills through a sample sales dataset.
